# Provenance of the original pair

Acquisition and merge receipts, the exposure correction, the analysis plan frozen before the
later-vintage extraction, and an offline replay verifier for the pair that motivated the study,
CU-select and BPagano-RtDriven. These records come from the first, two-model version of the audit
(September 2026) and are kept unchanged so its receipts can be checked.

- supplement/access/: SHA-256 and git blob identity of every file read
- supplement/acquisition.json: pull requests, merge times and ancestry checks
- supplement/analysis-plan.json: the declared catalogs and box, frozen before the later extraction
- supplement/replay.py: recomputes the original pair's results offline from the recorded values
- rights/: license texts and metadata for CU and BPagano, and the JHU CSSE terms
